# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина электроники и товаров для дома, разработанную с использованием Bootstrap.

Предметная область та же, что в контрольной работе №1, но это отдельная реализация в отдельном репозитории.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap 5.3.8 через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ на всю ширину через `container-fluid`;
- сетка популярных товаров (`col-12 col-md-6 col-lg-4`);
- подвал страницы.
