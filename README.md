# Bootstrap Shop — интернет-магазин на Bootstrap

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

Сайт на GitHub Pages: https://skylongg.github.io/kr2-bootstrap-shop/

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Bootstrap Shop — учебный интернет-магазин электроники и товаров для дома: каталог товаров,
страница товара, заявка на покупку и контакты.

Предметная область та же, что в контрольной работе №1, но это отдельная реализация
в отдельном репозитории. Интерфейс собран на сетке и компонентах Bootstrap,
собственный CSS используется только для небольших правок.

## Ссылка на опубликованную версию

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

В проекте Bootstrap подключён локально. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключается после Bootstrap, чтобы можно было переопределять отдельные стили:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

`bootstrap.bundle.min.js` подключается перед `</body>`. Он нужен для мобильного меню, выпадающего меню,
модального окна, карусели, вкладок, accordion и уведомлений.

## Bootstrap-сетка

- `container` — основное содержимое страниц;
- `container-fluid` — блок преимуществ на главной с фоном на всю ширину;
- `row` и `col-*` — строки и колонки;
- `col-12 col-md-6 col-lg-4` — карточки товаров: 1 колонка на телефоне, 2 на планшете, 3 на компьютере;
- `col-12 col-lg-6` — hero-блок и страница товара: две колонки на больших экранах;
- `g-3`, `g-4` — отступы между колонками.

## Реализованные компоненты

- `navbar` — единая навигация на всех страницах, сворачивается на мобильном;
- `dropdown` — меню «Дополнительно»;
- `card` — карточки товаров, форма заявки, похожие товары;
- `btn` — кнопки `btn-primary`, `btn-outline-primary`, `btn-outline-secondary` и другие;
- `badge` — значки «Хит», «Новинка», «Скидка», «Нет в наличии»;
- `alert` — сообщения на страницах каталога, товара и заявки;
- `modal` — быстрая заявка из каталога;
- `form-control`, `form-select`, `input-group`, `form-check` — формы заявки и обратной связи;
- `accordion` — частые вопросы на странице товара;
- `carousel` — акции на главной;
- `tabs` — описание, характеристики и доставка на странице товара;
- `toast` — уведомление после отправки формы;
- `breadcrumb` — хлебные крошки;
- `list-group` — контакты и преимущества товара;
- `table` — характеристики товара и пункты выдачи.

## Самостоятельные доработки

- Bootstrap подключён локально из папки `vendor/bootstrap/` вместо CDN.
- Добавлена пятая страница `contacts.html`: контакты, форма обратной связи, таблица пунктов выдачи.
- На главной добавлена карусель акций (`carousel`), популярные товары оформлены карточками с картинками.
- Каталог расширен до 9 товаров с картинками и категориями.
- Добавлен фильтр каталога по категориям (Электроника, Аксессуары, Дом) и счётчик найденных товаров.
- Добавлены варианты карточек: «Хит» с синей рамкой, старая цена у товаров со скидкой, «Нет в наличии» с неактивной кнопкой и бледной картинкой.
- В модальном окне показывается название товара, на котором нажали «Заказать».
- Формы проверяются в стиле Bootstrap: под неверным полем появляется подсказка, фокус переходит на первое неверное поле.
- После отправки формы показывается уведомление `toast`, форма очищается, модальное окно закрывается.
- В форму заявки добавлены количество и способ получения. Кнопка «Оформить заявку» на странице товара открывает форму с уже выбранным товаром (`order.html?product=laptop-sleeve`).
- На странице товара добавлены вкладки (`tabs`), список преимуществ (`list-group`) и похожие товары.
- Карточки товаров слегка поднимаются при наведении.
- У всех страниц есть `meta description` и иконка сайта.
- Проект опубликован через GitHub Pages.

## Как проверить

- Открыть ссылку GitHub Pages.
- Проверить навигацию на всех страницах и меню «Дополнительно».
- Уменьшить окно до 375px в DevTools и раскрыть мобильное меню.
- На главной пролистать карусель стрелками.
- В каталоге переключить фильтр по категориям и проверить счётчик.
- Нажать «Заказать», отправить пустую форму и проверить подсказки под полями.
- Заполнить форму в модальном окне и проверить уведомление об отправке.
- На странице товара переключить вкладки и раскрыть частые вопросы.
- Нажать «Оформить заявку» и проверить, что товар уже выбран в форме.
- Открыть `contacts.html` и отправить форму обратной связи.
- Проверить страницы на ширине 375px, 768px, 1024px и 1440px.
