# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина электроники и товаров для дома, разработанную с использованием Bootstrap.

Предметная область та же, что в контрольной работе №1, но это отдельная реализация в отдельном репозитории.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap 5.3.8 через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ на всю ширину через `container-fluid`;
- сетка популярных товаров (`col-12 col-md-6 col-lg-4`);
- подвал страницы.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация с выпадающим меню «Дополнительно»;
- создана страница каталога `catalog.html`;
- создана страница товара `product.html`;
- создана страница заявки `order.html`;
- использованы компоненты `navbar`, `dropdown`, `card`, `btn`, `badge`, `alert`, `modal`, `breadcrumb`, `table`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`;
- в карточки товаров добавлены картинки из папки `images/`;
- в `css/custom.css` добавлены минимальные стили для картинок карточек;
- проект подготовлен к сдаче контрольной работы №2.

## Самостоятельные доработки

- Bootstrap подключён локально из папки `vendor/bootstrap/` вместо CDN.
- Добавлена страница `contacts.html`: контакты (`list-group`), форма обратной связи, таблица пунктов выдачи.
- На главной вместо заглушки добавлена карусель акций (`carousel`), популярные товары оформлены через `card` с картинками.
- Каталог расширен до 9 товаров, добавлен фильтр по категориям и счётчик найденных товаров.
- Добавлены варианты карточек: «Хит» с рамкой, старая цена у товаров со скидкой, «Нет в наличии» с неактивной кнопкой.
- В модальном окне показывается название выбранного товара.
- Формы проверяются в стиле Bootstrap (`needs-validation`, `invalid-feedback`), после отправки появляется уведомление `toast`.
- В форму заявки добавлены количество и способ получения; товар подставляется по ссылке `order.html?product=...`.
- На странице товара добавлены вкладки (`tabs`), список преимуществ (`list-group`) и похожие товары.
- Карточки товаров слегка поднимаются при наведении.

## Используемые технологии

- HTML;
- Bootstrap 5.3.8;
- CSS;

- Git;

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — форма заявки;
- `contacts.html` — контакты и обратная связь;
- `css/custom.css` — дополнительные стили проекта;
- `js/main.js` — проверка форм, фильтр каталога, уведомления;
- `images/` — изображения товаров и иконка сайта;
- `vendor/bootstrap/` — локальные файлы Bootstrap;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.
